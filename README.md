# Barangay DataHub
A web-based barangay data management system built with Django and PostgreSQL.

## Live Demo
https://brgy-datahub.onrender.com

## Features
- Resident management
- Household management
- Facilities management
- Reports and dashboard
- Role-based user access

## Tech Stack
- Python / Django 4.2
- PostgreSQL
- WhiteNoise (static files)
- Deployed on Render.com
